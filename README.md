# TypeSprint

موقع بسيط لتعلم الكتابة السريعة يدعم اللغتين العربية والإنجليزية.

## التشغيل

1. افتح المجلد الحالي.
2. شغِّل خادمًا محليًا:

```bash
cd /Users/salahabdullah/Documents/Projects/typeing
python3 -m http.server 8000
```

3. افتح الرابط التالي في المتصفح:

```text
http://localhost:8000
```

## الميزات

- تدريب كتابة سريع باللغة العربية
- تدريب كتابة سريع باللغة الإنجليزية
- عداد WPM
- نسبة الدقة
- مؤقت 60 ثانية
- عداد الأخطاء
- اختبار جديد تلقائي
